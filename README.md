# 🛒 Customme — Online Shop Landing Page

A modern, responsive, and pixel-perfect e-commerce landing page built with clean, semantic web technologies. Designed for a seamless user experience across all device screens.

## ✨ Key Features

* 📱 **Fully Responsive:** Optimized for Mobile, Tablet, and Desktop displays using CSS Grid & Flexbox.
* 🎨 **Clean CSS Architecture:** Structured with CSS Variables for easy theme and color customization.
* 🧩 **BEM Methodology:** Maintainable, predictable, and scalable class naming conventions.
* 🔤 **Persian Typography:** Full RTL support configured with custom Persian web fonts.
* ⚡ **High Performance:** Lightweight, dependency-free code for fast load times.

---

## 🛠️ Tech Stack

* **HTML5:** Semantic structural markup.
* **CSS3:** Modern layouts, design tokens, responsive breakpoints, and UI transitions.
* **JavaScript (ES6+):** Interactive UI elements and DOM manipulation.

## 🚀 Quick Start

1. **Clone the repository:**

   ```bash
   git clone https://github.com/mhniknia/customme-shop.git
   ```

2. **Navigate to the project directory:**

   ```bash
   cd customme-shop
   ```

3. **Open `index.html` in your browser.**
